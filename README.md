## 🚀 First-Time Setup Guide

Once the app opens in your browser, here's what to do:

1. **Find the Settings/Configuration** – Look for a gear icon ⚙️ or "Settings" button on the main screen.
2. **API Base URL** – The app works with OpenAI-compatible services. If you're using Hetzner's free API, it should be pre-configured. If not, enter: `https://experimental.hetzner.dev`
3. **Select a Model** – Choose from available models like `Qwen/Qwen2.5-72B-Instruct` or other listed options.
4. **Click "Connect" or "Save"** – The app will test the connection.
5. **Start Chatting!** – Type your question in the chat box and press Enter.

If you don't see these options, don't worry – the app might work out-of-the-box with default settings.

## 🛠️ Troubleshooting Common Issues

| Problem | Solution |
|---------|----------|
| **App won't open** | Make sure you extracted the ZIP file completely. Try double-clicking `index.html` again. |
| **Blank white page** | Close the browser tab and reopen it. If that fails, try a different browser (Chrome, Edge, or Firefox work best). |
| **Connection error** | Check your internet connection. Also, ensure you're not behind a strict firewall that blocks API calls. |
| **Models not loading** | The free API might be temporarily busy. Wait a few minutes and try again. |
| **Slow responses** | This is normal with free AI services. Large models take time to respond. |
